# Ember & Ivy

Premium café, restaurant, cocktail lounge and live music venue — Lakeside, Pokhara, Nepal.

`Where Great Coffee Meets Great Evenings.` Open daily 7:00 AM – 1:00 AM · ⭐ 4.7 · 19+ reviews.

## Stack

- React 18 + Vite 5 (SPA)
- React Router (Home, Menu, Gallery, Events, Reservation, Contact, Admin)
- Framer Motion (reveals, hero, smooth animations)
- Supabase (content, reservations, settings, analytics) — optional
- EmailJS (reservation + contact + newsletter email) — optional
- Hand-rolled design system (dark luxury theme, light mode, glassmorphism)

Everything runs **with zero configuration** in demo mode (content from seed, admin CRUD persists to localStorage). Add Supabase and EmailJS keys to go live.

## Run locally

> Note: the folder name contains `&` (Ember & Ivy), which breaks `npm` script resolution on
> Windows `cmd`. The scripts call vite through `node` with a relative path to work around it.

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
npm run preview
```

## Environment

Copy `.env.example` to `.env.local` and fill in what you have:

| Variable | Purpose |
| --- | --- |
| `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY` | Backend content + reservations. Run `supabase/schema.sql` first. |
| `VITE_EMAILJS_SERVICE_ID` / `TEMPLATE_ID` / `PUBLIC_KEY` | Send reservation/contact/newsletter emails. |
| `VITE_ADMIN_EMAIL` / `VITE_ADMIN_PASSWORD` | Demo-mode admin login (default `admin@emberandivy.com` / `ember-admin`). |
| `VITE_EMAIL` / `VITE_PHONE` | Contact info shown across the site. |
| `VITE_WATERMARK` | Optional footer credit line; leave empty to hide. |

## Admin panel

Open `/admin`. With Supabase configured you sign in with the email/password user you create under **Auth → Users**; existing accounts are made admins automatically. Otherwise use the demo credentials above.

Three access levels (set under **Users & Access**):

- **Admin** — everything: content, reservations, page settings, users, uploads.
- **Employee** — content only (menu, gallery, events, …) + image uploads.
- **Client** — a guest portal showing only their own reservations (with self-serve cancel).

Manage: dashboard stats · menu items · categories · gallery · reviews · reservations (confirm/cancel) · events · home banner · team · Instagram feed · user accounts · settings & theme. Every photo field has an **Upload picture** button that auto-compresses the image (WebP) — nothing to configure.

## Supabase setup

1. Create a project at [supabase.com](https://supabase.com).
2. Open **SQL Editor** and run `supabase/schema.sql`.
3. Enable **Auth → Providers → Email**, then add a user under **Auth → Users**.
4. Copy the project URL + anon key into `.env.local`.

## Deployment

Works on Vercel or Netlify out of the box (SPA rewrites included):

```bash
npm run build
```

- **Vercel:** import repo, framework preset `Vite`. `vercel.json` included.
- **Netlify:** build `npm run build`, publish `dist`. `netlify.toml` included.

Remember to add the same env vars in your host's settings.
